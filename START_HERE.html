Open LayerLoom

On a Mac? The standalone Mac app is the easiest option. Download its DMG, copy the app to Applications, and open it.

This is the source download. Its launcher sets up Python for you. You do not need Git, a GitHub account, or programming experience.

  1. Extract the whole ZIP. On Windows, right-click it and choose Extract All. On Mac, double-click it. Open the extracted folder; keep all its files together.
  2. Open the launcher for your computer.

    Windows x64: double-click Launch LayerLoom.bat (its type may say Windows Batch File). Mac: double-click Launch LayerLoom.command.

    Linux x64: in a terminal in this folder, run bash "Launch LayerLoom.sh". Linux needs working desktop graphics libraries; see the installation guide below.

  3. Wait for the app to open. First setup needs internet and may take several minutes. Keep its setup window open, including while LayerLoom is running. You do not need to type Python commands.
  4. Try the example. Choose Try the example on the build plate, then Weave. Keep Woven apparent colors and 0.16 mm, choose a save location, and wait for Export complete. Use Show in Finder or Show in folder to find your printable model.

If something stops you

Windows security prompt: for the launcher from your LayerLoom download, choose Run in “Open File – Security Warning.” If you see “Windows protected your PC,” use More info → Run anyway if available. Managed computers may need administrator approval.

Mac source launcher blocked: dismiss the warning, then open System Settings → Privacy & Security and look for an approval message naming the launcher. If it cannot execute, use the source-specific recovery steps in the installation guide, or use the standalone Mac app above.

Interrupted setup: reconnect to the internet and open the same launcher again. Keep the extracted folder for future launches. Do not move it after setup unless you are prepared to repeat the installation.

What are these files?

3MF (.3mf)
A 3D-printing model. LayerLoom exports one with separate filament parts. Open it in your slicer, keep the parts aligned, assign their filaments, and use the same 0.16 mm layer height for this example.
GLB (.glb)
A 3D model that can include colors. You can import one later; you do not need one to try the included examples.
LayerLoom project (.llpaint)
Your editable model and surface paint. Save this if you want to edit the paint later; export a separate 3MF to print.

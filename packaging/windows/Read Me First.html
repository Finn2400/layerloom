Start LayerLoom

Windows · early access

  1. Open the downloaded LayerLoom setup file and choose Install. It installs for your account without an administrator password.
  2. Choose Finish to open LayerLoom. Later, find LayerLoom in the Start menu.
  3. Click Load example, then Weave. Keep Woven apparent colors and 0.16 mm, then choose where to save.
  4. When it finishes, click Show in folder. Your 3MF is a printable model file; open it in your slicer to prepare it for your printer.

No Python, Git, Terminal, or printer is needed to try the example. The installed app works offline.

Windows blocked the installer?

This free build is unsigned. If SmartScreen says Windows protected your PC, verify that you downloaded it from the LayerLoom GitHub repository, then choose More info → Run anyway, if offered. If Windows reports malware or your organization blocks it, stop and report the exact message. Do not disable antivirus or Windows security.

Portable ZIP instead of setup?

Right-click the ZIP and choose Extract All. Open the extracted LayerLoom folder and double-click LayerLoom.exe. Keep the whole folder together, including _internal and worker. Do not run it from inside the ZIP.

If something goes wrong

Choose Help → Diagnostic logging → Start diagnostic logging, reproduce the problem, then stop and copy the summary. Logs stay on your computer. Report a problem. Slicer walkthrough.

For 64-bit Intel/AMD Windows PCs. Windows on ARM is not yet validated. Uninstall from Windows Settings → Apps; your saved models are kept.

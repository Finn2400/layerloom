Version 0.6.4a2 — Paint test candidate

This disk image contains the Mac app and its required libraries. You do not need to install Python, Git, Node, or Homebrew.

Draft build for testing. This release is unpublished and available only to maintainers with repository write access. Automated checks do not replace the required downloaded-app and first-time-user checks. Public users can use the source launchers until a desktop release is published.

2. Copy and open

  1. Drag LayerLoom.app onto the Applications folder in this disk image. You can copy it to another folder you own if Applications is not writable.
  2. Open the copied app in Finder. You can eject the disk image after copying.
  3. If macOS says the developer cannot be verified or Apple cannot check the app, dismiss that alert. Open Apple menu → System Settings → Privacy & Security and scroll to Security.
  4. Find the message naming LayerLoom and choose Open Anyway (some versions first show Open). Confirm the next prompt and enter your Mac login password if asked. Only approve the copy supplied by the LayerLoom project.

If the approval button is missing, try opening the copied app again and return to Settings. The button is offered for about an hour after a launch attempt. This Settings route applies to macOS 14 Sonoma, 15 Sequoia, and 26 Tahoe; labels can vary by update.

This free build is ad-hoc signed without Apple notarization. Approval may be required again after an update. A managed Mac may prohibit approval; contact its administrator. If the alert says the app is damaged or will damage your computer, stop and obtain a fresh copy from the project. Report the exact message if it persists.

3. Make your first model

  1. Click Try the example. Four CMY cubes appear in Paint.
  2. Click Export geometry 3MF…. The tutorial selects Woven apparent colors and 0.16 mm automatically. Check those values and confirm.
  3. Choose a .3mf filename in Documents and wait for the completion message. Use Show in Finder to locate it. The first export may take longer while geometry search code compiles.
  4. Open that file in your slicer as one model with multiple parts. Keep the parts aligned and match the cyan, magenta, and yellow objects to your filaments. Use 0.16 mm for both normal and first layers, with adaptive layers disabled.

4. Try painting

  1. With the cubes open, choose Surface select, click a surface, choose a color, and click Apply paint.
  2. Try Undo and Redo. Choose Save paint… and save a .llpaint project in Documents. Use Open… to reopen it and check your edit.
  3. Export a separate .3mf for printing. The project retains editable paint; the printable output converts those colors into separate physical filament geometry.

Start with the cubes. Help → Load the Benchy example opens the larger model, which selects a 4,096 MiB estimated export budget. Cubes and ordinary models use 2,048 MiB. The export summary shows the budget; it is not a hard limit on total memory, and larger models take longer.

After first-open approval, the example works offline. Outputs stay in the folder you choose. To update, quit LayerLoom and replace the app; keep your models outside the app.

If something goes wrong

Use Help → Copy diagnostics and Help → Open logs. If the app cannot start, its error dialog gives details and a log location. Include the exact message, Mac model, macOS version, and the step that failed when reporting the issue.

This is a **draft** standalone Mac release. It contains separate Apple Silicon (macOS 14+) and Intel (macOS 15+) applications with Python and GUI dependencies included.

Download the DMG matching your Mac, drag LayerLoom to Applications, open it, then choose **Try the example → Weave**. If macOS blocks the app, follow **System Settings → Privacy & Security → Open Anyway**, as described in the attached first-run instructions. The free build is ad-hoc signed and is not notarized.
